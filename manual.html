01 / LOGIN

登入系統

選擇自己的使用者名稱。

輸入 4–6 位數 PIN，按「登入系統」。

PIN 請勿提供給其他人。若忘記 PIN，可由試算表擁有者在「使用者」工作表的 C 欄重設。

02 / TIMER

即時計時

開冷氣時按「開始計時」。

首頁會持續顯示本次使用時間；即使跨夜，計時仍會繼續。

關冷氣時按「結束計時」，系統會儲存開始、結束時間及時數。

同一時間只允許一位使用者計時，避免同一台冷氣被重複計費。

03 / QUICK ENTRY

補登與跨日紀錄

輸入實際「開始日期與時間」。

輸入實際「結束日期與時間」。隔夜使用時，結束日期須選隔天。

視需要填寫備註，再按「新增紀錄」。

隔夜範例

開始：2026/08/10 22:30　結束：2026/08/11 04:00，共 5.5 小時。

04 / RECORDS

查看及刪除紀錄

從左側選單進入「使用紀錄」，可依使用者與月份篩選。只有建立紀錄的本人可以刪除自己的資料；刪除後無法從網站復原。

05 / COST SPLIT

使用比例與電費分攤

首頁圓餅圖以本月四位使用者的冷氣使用時數計算比例。輸入本月總電費後，系統會以相同比例列出每人的分攤費用。

個人費用 ＝ 總電費 × 個人本月時數 ÷ 全員本月時數

總電費只保存在目前瀏覽器，不會寫入 Google 試算表；更換裝置或使用無痕模式時需重新輸入。

06 / PROFILE

修改名稱與 PIN

進入「個人設定」，輸入目前 PIN 後即可修改顯示名稱或設定新 PIN。新 PIN 必須是 4–6 位數字。

若 PIN 以 0 開頭，Google 試算表可能移除開頭的 0。建議避免使用此類 PIN，或先把 PIN 欄設為「純文字」。

07 / DATA

資料存放位置

工作表保存內容
使用者ID、名稱、PIN、代表顏色
使用紀錄使用者、開始時間、結束時間、時數與備註
系統狀態目前正在計時的使用者及開始時間

工作表位於綁定 Apps Script 的 Google 試算表底部，不在 Apps Script 的「部署作業」頁面。

08 / HELP

疑難排解

無法連接試算表或出現 CORS

確認 Apps Script 設為「執行身分：我」及「誰可以存取：任何人」，並確認 config.js 使用最新的 /exec 網址。

本機正常，但 GitHub Pages 異常

等待 GitHub Pages 更新後重新開啟頁面，不要沿用發布前已開啟的舊分頁。

修改 PIN 後無法登入

在試算表的「使用者」工作表檢查 PIN、移除空格，並確認選擇正確使用者。

無法新增紀錄

確認開始與結束日期時間皆已填寫，且結束時間晚於開始時間。
